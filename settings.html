Director's Framework

Run a chain of your own thinking steps - each with its own prompt, its own Connection Profile, and optional tool calls - before the final reply. The combined result is injected into the final prompt and, optionally, written into the reply's reasoning block.

Memory (experimental)

Every reply is embedded and stored per-chat via SillyTavern's own vector search (the free, local transformers source - no API key, no extra setup). Stages with "short-term memory" turned on get the most relevant past replies pulled back into their context, not just the last few messages. First use downloads the embedding model on the server once, so the first reply after turning this on may be a bit slower.

Forget this chat's short-term memory

Every N replies, the last N messages are compressed into a short summary by an LLM call and moved from short-term into medium-term - so old detail isn't lost when it ages out of short-term, just condensed. Needs its own Connection Profile (usually a fast/cheap one is enough).

Forget this chat's medium-term memory

Facts you pin by hand - never written or deleted automatically. Works independently of short/medium-term: you can pin and recall facts even with those turned off. Pin from a stage's output in the Last run log below, or add one directly here.

Revise

Adds a button to every AI message (in "Message Actions"). Click it, pick a template (or type your own instruction), and that one message is rewritten in place - the reply SillyTavern already generated is the draft, so this edits it directly rather than running a shadow draft through the pipeline. A undo button appears once a message has been revised.
